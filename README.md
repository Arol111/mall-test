# 商城后台管理系统测试项目

## 项目简介

本项目基于 macrozheng/mall 开源商城后台管理系统开展软件测试实践。

主要完成：

- 功能测试
- 接口测试（Postman）
- 数据库验证（MySQL）
- 测试用例设计
- 缺陷跟踪
- 测试报告编写

## 测试模块

- 登录认证
- 商品管理
- 商品分类
- 品牌管理
- 订单管理
- 权限管理
